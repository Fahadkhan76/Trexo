# Trexo — Lean Development Roadmap

## Stage 1 — Frontend foundation

**Status: Completed**

Existing UI, navigation, billing, inventory, and interactions stabilized.

## Stage 2 — Intelligence foundation

**Status: Next**

Make the existing ML pipeline run reliably and validate its outputs.

- Prepare datasets and model artifacts.
- Validate demand forecasting.
- Validate dead-stock risk detection.
- Verify reorder calculations.
- Fix critical model issues.

## Stage 3 — Integration and decision engine

**Status: Pending**

Connect the ML engine to the existing Trexo frontend.

- Build a lightweight FastAPI backend.
- Connect forecasting and dead-stock predictions.
- Connect reorder recommendations.
- Build Smart Purchase Planner.
- Make recommendations respond to changing demo data.

## Stage 4 — Demo polish and impact

**Status: Pending**

Make the solution convincing to judges.

- Show money trapped in slow-moving stock using clearly labelled demo estimates.
- Show stockout risks.
- Show prioritized purchase recommendations.
- Demonstrate a complete shopkeeper workflow.
- Prepare architecture and ML evaluation results.
