# Guidance for coding agents

Before planning or implementing an upgrade to Trexo, read both:

- [`ROADMAP.md`](ROADMAP.md) for the intended stages and priorities.
- [`day1Report.md`](day1Report.md) for the current repository capabilities, architecture, and known limitations.

Use these documents together with the current code to establish what is already implemented, what remains planned, and whether the requested upgrade fits the roadmap. Treat roadmap statuses as planning context and verify implementation details against the code before changing them.
